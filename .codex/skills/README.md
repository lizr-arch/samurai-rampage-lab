# Repo Local Skills

本目录存放只服务于 `samurai-rampage-lab` 的本地 skill。

推荐结构：

1. 一个 skill 一个目录
2. 目录内必须有 `SKILL.md`
3. 需要复用模板、示例、检查表时，放在该 skill 的子目录里
4. 本仓库约定统一放在 `.codex/skills/` 下，便于随仓库一起共享和维护

当前可用：

1. `demo-web-feature-docs`
   - 路径：[`demo-web-feature-docs/SKILL.md`](./demo-web-feature-docs/SKILL.md)
   - 用途：更新 `apps/demo-web` 相关的功能文档、专题文档和 `docs/features/changelog.md`

推荐说法：

1. `用 demo-web-feature-docs skill 写文档`
2. `按仓库文档 skill 更新 changelog 和功能点文档`
