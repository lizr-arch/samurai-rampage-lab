# 26 Banner Placement v0.1

## 1. 目标

本阶段验证：

1. 主帅发令更像在战场上投放军旗
2. 玩家先选军旗，再进入投放模式
3. 玩家能在战场看到范围预览、落旗实体和目标反馈
4. 令旗、CD 和 mock event 形成完整闭环

## 2. 为什么采用点击后投放

当前采用：

1. 点击军旗按钮进入 armed 状态
2. 鼠标进入战场投放模式
3. 点击战场完成落旗

这样比“点击即生效”更像主帅发令，也比“拖拽按钮到战场”更不容易和拖兵冲突。

同时避免把系统做成：

1. 右键 RTS 命令
2. 拖拽技能图标
3. 单位技能栏即时释放

## 5. 投放交互

交互闭环：

1. 选择主帅
2. 点击一个军旗按钮
3. 进入投放模式
4. 鼠标移动时显示范围预览
5. 预览圈内蓝方兵团高亮
6. 点击战场合法区域落旗
7. 扣除令旗并进入 cooldown
8. 生成短时存在的军旗实体
9. 目标兵团显示短暂反馈
10. DevHarness 记录 `banner_order_placed`

取消方式：

1. 再次点击当前 armed 军旗
2. 按 `Esc`
3. 右键战场

## 6. 设计边界

当前明确不做：

1. 真实行为执行
2. battle-core 接入
3. 右键命令系统
4. 框选
5. 拖拽军旗
6. 画线
7. 战术暂停
