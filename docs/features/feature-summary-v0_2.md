# Feature Summary v0.2

本文档用于记录 `apps/demo-web` 在 `v0.2` 阶段新增后的功能基线。

本阶段重点不再是静态 UI 骨架，而是把 `BattleField` 提升为可观察、可编辑的战斗沙盘。

---

## 1. 当前范围

当前总结范围覆盖：

1. 正式 `game-frame`
2. `BattleField`
3. 左右 ArmyPanel
4. 左右兵种托盘
5. BottomCommandBar / MiniMap
6. DevHarness
7. 与战斗测试相关的缩放、拖放、删除、预设填充交互

当前不覆盖：

1. `packages/battle-core`
2. `packages/battle-rules`
3. 真实战斗结算
4. 真实事件流

---

## 2. v0.2 核心新增

### 2.1 BattleField Zoom

已完成：

1. 主战场支持鼠标滚轮缩放
2. 缩放范围为 `1.0x ~ 2.5x`
3. 缩放中心跟随鼠标位置
4. 缩放后可在战场空白区域拖动画面
5. 双击战场空白区域恢复默认视图
6. 右下角显示当前缩放倍率

当前意义：

1. 可以观察局部兵团交战
2. 可以放大看单位美术差异
3. 现有拖拽和选择不再依赖全局视图

### 2.2 双侧兵种托盘

已完成：

1. 左侧蓝方托盘
2. 右侧红方托盘
3. 每侧托盘一次性展示全部 6 种兵种
4. 托盘显示当前上场数量 / 上限数量
5. 达到上限后托盘进入满员态

当前兵种：

1. 足轻
2. 枪兵
3. 弓兵
4. 铁炮
5. 骑兵
6. 忍者

### 2.3 拖兵上场

已完成：

1. 蓝方可从左托盘拖兵进左半场
2. 红方可从右托盘拖兵进右半场
3. 同一种兵允许重复上场
4. 每边最多上场 8 队
5. 新单位上场后同步进入：
   - 战场
   - ArmyPanel
   - MiniMap

当前规则：

1. 只能投放到本方半场
2. 不能与同侧其他单位明显重叠
3. 超过上限时不允许继续投放

### 2.4 单位删除

已完成：

1. 战场单位支持右键删除
2. 删除后同步移除：
   - 战场单位
   - ArmyPanel 条目
   - MiniMap 点位
3. 当前仍保留拖回托盘删除的兼容路径

当前定位：

1. 右键删除是主删除方式
2. 适合快速清场和重新摆阵

### 2.5 兵种独立美术

已完成：

1. 蓝方 6 张独立单位图
2. 红方 6 张独立单位图
3. `UnitSquad` 不再只分 `melee / ranged`
4. 当前直接按兵种 archetype 渲染资源

当前意义：

1. 放大后能区分不同兵种
2. 战场上不再只是“近战一类、远程一类”
3. 兵种卡、战场单位、战术理解开始统一

### 2.6 Run 语义调整

已完成：

1. `Run 1v1 / Run 5v5` 现在使用当前布阵
2. 运行不会覆盖玩家刚摆好的阵容
3. `Scenario Preset` 改为模板填充入口
4. `Reset Battle` 恢复默认模板态

当前含义：

1. 预设负责“快速生成样本”
2. Run 负责“拿当前战场去跑 mock 结果”

---

## 3. 当前交互能力

### 3.1 Selection Sync

仍然保留：

1. 侧栏点选
2. 战场点选
3. `SelectedUnitChip`
4. MiniMap 高亮同步

### 3.2 战场再拖拽

仍然保留：

1. 已上场单位可再次拖动
2. 蓝方只能留在左半场
3. 红方只能留在右半场
4. 非法落点回退

### 3.3 阵型按钮

当前仍只控制蓝方阵型重排：

1. 锋矢阵
2. 鹤翼阵
3. 鱼鳞阵

当前说明：

1. 它现在作用于“当前蓝方已上场单位”
2. 不再依赖固定 5 支队伍

### 3.4 Random Formation

当前行为：

1. 只随机当前已上场单位的位置
2. 不改兵种构成
3. 不改当前双方队数

---

## 4. 当前边界

当前已明确不做：

1. battle-core 驱动的真实战斗
2. cost / 编制 / 兵种限制系统
3. 网格吸附
4. 批量编队
5. 模式切换（布阵模式 / 战斗模式）
6. AI 自动部署

当前仍属于：

1. mock 驱动的战斗沙盘
2. 产品 / 交互 / 视觉验证层
3. 真实战斗接入前的原型环境

---

## 5. 当前适合的测试用途

当前最适合验证：

1. 兵种差异是否足够可见
2. 双方自由部署是否顺手
3. 不同兵种组合的战场阅读性
4. 缩放后局部交战是否清晰
5. Run 是否能承接当前编辑态战场
6. 删除、补兵、重排的快速循环效率

---

## 6. 人工验证建议

1. 确认左右托盘一次能看到全部 6 种兵
2. 拖同一种兵多次上场，确认允许重复
3. 每边上场到第 8 队后，确认继续拖放失败
4. 右键删除任意单位，确认战场 / 侧栏 / 小地图同步移除
5. 滚轮放大到 `2.5x`，确认枪兵、骑兵、弓兵、铁炮、忍者轮廓可分辨
6. 自定义摆阵后点击 `Run 1v1 / Run 5v5`，确认不会把当前阵容重置

---

## 7. 当前结论

截至 `v0.2`，`demo-web` 已经从“可看 UI 样板”进入“可编辑战斗沙盘”阶段。

现在它具备：

1. 可缩放观察
2. 可拖兵构阵
3. 可重复上场
4. 可右键删兵
5. 可基于当前布阵运行 mock 场景

这份文档应作为后续继续接编队规则、cost、正式部署模式前的基线记录。
