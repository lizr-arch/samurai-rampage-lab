# Feature Summary v0.5

本阶段把 `demo-web` 的主帅发令从“点击型军令”调整为“投放型军旗”原型。

核心闭环：

1. 选主帅
2. 选军旗
3. 进入投放模式
4. 预览范围
5. 点击落旗
6. 看目标反馈
7. 看令旗 / CD / mock event

## 1. 当前范围

当前覆盖：

1. 双主帅切换
2. 双军旗按钮
3. 战场投放预览圈
4. 投放后短时存在的军旗实体
5. DevHarness `banner_order_placed`

当前不覆盖：

1. 真实战斗
2. 真实移动
3. 真实属性变化
4. 敌方 AI 发令

## 2. v0.5 核心新增

### 2.1 军旗按钮改为 Armed 流程

1. 点击底部军旗按钮进入 armed 状态
2. 再次点击可取消
3. cooldown 或令旗不足时不可进入 armed
4. 底部栏明确显示 `投放模式中`

### 2.2 战场预览

1. 投放模式下，鼠标移动显示半透明范围圈
2. 预览圈内蓝方兵团高亮
3. 预览提示显示预计影响数量
4. 投放模式期间临时禁用单位拖拽，防止和布阵冲突

### 2.3 落旗实体

1. 点击战场后生成军旗实体
2. 军旗显示短标签 `冲` 或 `集`
3. 军旗范围环保留约 5 秒
4. 到时自动淡出

### 2.4 目标反馈和事件

1. 范围内目标兵团头顶显示短反馈
2. 冲锋旗显示 `冲`
3. 集结旗显示 `集`
4. DevHarness 追加 `banner_order_placed`
5. `恢复令旗` 仍然可用

## 3. 当前边界

1. 仍未接 battle-core
2. 仍未实现真实冲锋或集结
3. 不支持右键命令、框选、画线
4. 不支持拖拽军旗到战场
