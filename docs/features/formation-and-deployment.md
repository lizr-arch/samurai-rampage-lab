# Formation and Deployment v0.2

本文档记录 `apps/demo-web` 当前与阵型、布阵、拖拽摆位相关的功能。

目标：

1. 明确当前阵型功能已经做到哪里
2. 明确蓝红双方拖拽布阵的规则
3. 为后续战斗测试、开战前部署、真实战斗接入提供基线

---

## 1. 当前定位

当前阵型与布阵能力属于：

1. UI 交互测试能力
2. 战斗前摆位能力
3. 开发测试用的轻量部署系统
4. 双侧兵种自由部署沙盘

当前不属于：

1. 真实战斗部署系统
2. 后端保存的正式阵型系统
3. battle-core 驱动的开战前准备流程

---

## 2. 当前已完成能力

### 2.1 Formation Presets

已完成：

1. 底部 `阵形` 按钮可点击
2. 点击后可循环切换蓝方预设阵型
3. 当前预设阵型包括：
   - `arrow` / 锋矢阵
   - `crane` / 鹤翼阵
   - `scale` / 鱼鳞阵

当前行为：

1. 点击 `阵形` 按钮时，蓝方单位位置立刻切换
2. 左侧 ArmyPanel 文本数据不变
3. 红方默认不跟随该按钮切换

### 2.2 Manual Deployment

已完成：

1. 蓝方单位可手动拖拽布阵
2. 红方单位可手动拖拽布阵
3. 拖拽成功后单位会停在新位置
4. 松手非法时回退原位置

### 2.3 Staging Tray Deployment

已完成：

1. 蓝方从左托盘拖兵上场
2. 红方从右托盘拖兵上场
3. 当前可上场兵种包括：
   - 足轻
   - 枪兵
   - 弓兵
   - 铁炮
   - 骑兵
   - 忍者
4. 同一种兵允许重复上场
5. 每边上场上限为 8 队

### 2.4 Delete From Battlefield

已完成：

1. 已上场单位支持右键删除
2. 删除后立即释放上场名额

### 2.5 Formation State Label

已完成：

1. 当前阵型状态会在底部标签显示
2. 点击预设阵型后，标签显示预设状态
3. 手动拖拽后，标签切到手动布阵状态

当前示例：

1. `锋矢阵 · 预设阵型`
2. `锋矢阵 · 手动布阵`

当前含义：

1. 阵型来源是预设还是手调可区分
2. 更适合开发测试时判断当前布局状态

## 3. 蓝方部署规则

### 3.1 蓝方可拖动

已完成：

1. 蓝方战场单位可以拖动
2. 拖动后保持选中同步
3. 蓝方拖动成功后会写回当前 UI 状态
4. 蓝方可从左托盘新增单位

### 3.2 蓝方区域限制

当前规则：

1. 蓝方单位只能放在 `BattleField` 左半区
2. 不允许拖到右半区
3. 不允许拖出战场边界

### 3.3 蓝方预设关系

当前规则：

1. 点击 `阵形` 时，蓝方优先应用预设
2. 预设后仍允许继续手动拖动微调
3. 一旦手动拖动，当前状态记为 `手动布阵`
4. 当前蓝方不是固定 5 支队伍，可基于当前已上场队伍重排

---

## 4. 红方部署规则

### 4.1 红方可拖动

已完成：

1. 红方战场单位可以拖动
2. 红方拖动后保持选中同步
3. 红方拖动成功后会写回当前 UI 状态
4. 红方可从右托盘新增单位

### 4.2 红方区域限制

当前规则：

1. 红方单位只能放在 `BattleField` 右半区
2. 不允许拖到左半区
3. 不允许拖出战场边界

### 4.3 红方与预设关系

当前规则：

1. 当前 `阵形` 按钮主要作用于蓝方预设
2. 红方没有单独的预设阵型切换按钮
3. 红方仍可通过托盘和手动拖拽进行测试摆位

---

## 5. 合法性规则

### 5.1 边界限制

当前规则：

1. 单位不得拖出 `BattleField`
2. 蓝方不得越过中线到右侧
3. 红方不得越过中线到左侧

### 5.2 最小距离限制

当前规则：

1. 同侧单位之间存在最小距离要求
2. 若释放点距离同侧其他单位过近，则释放失败
3. 失败后回退到拖动前位置

当前说明：

1. 这是轻量规则
2. 当前不做复杂碰撞
3. 当前不做自动避让

### 5.3 非法释放回退

当前规则：

1. 释放在非法半区时回退
2. 释放在边界外时回退
3. 释放在过近位置时回退

### 5.4 上场数量限制

当前规则：

1. 每边最多上场 8 队
2. 超过上限时托盘不应继续成功投放

### 5.5 删除规则

当前规则：

1. 右键已上场单位可直接删除
2. 删除后战场、侧栏、小地图同步移除

---

## 6. 当前交互反馈

### 6.1 拖动状态反馈

当前要求：

1. 拖动中单位需要提升层级
2. 拖动中单位需要有视觉强调
3. 鼠标移上可拖动单位时，应有明确交互暗示

### 6.2 可布阵区域反馈

当前要求：

1. 蓝方拖动时显示左半区 overlay
2. 红方拖动时显示右半区 overlay
3. 非法拖动时显示错误倾向反馈
4. 当前托盘应能一次性看到全部 6 种兵

### 6.3 阵型状态反馈

当前要求：

1. 预设阵型与手动布阵必须能区分
2. 用户操作后标签应同步更新

5. 未来事件流接入前的战场布局预演
